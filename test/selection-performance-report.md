# 初始点选卡顿修复

2026-09-16，Electron 本地隔离测试；未修改用户任务数据。

根因：mousemove 对每个命中容器执行完整字段枚举，字段后处理又使用
`out.some(node.contains)`，在大容器上产生平方级遍历。300 个连续移动
事件会重复同步执行，阻塞网页线程。

修改：
- requestAnimationFrame 合并鼠标移动，最多每帧一次。
- 命中检测只查看最多 16 层堆叠元素、160 个后代，悬停不再调用全量字段提取。
- 打开选择菜单只判断是否有子节点，真正展开字段时再提取。
- 字段后处理改用祖先集合，移除两两比较。
- 退出模式取消待执行绘制。
- 页面加载等待结束时清理超时计时器及监听器；面板日志最多保留 500 条。

验证：
- 2,000 张卡片、300 次鼠标移动：旧版本 95 秒仍未返回，终止该隔离测试进程。
- 修复后同一规模：事件提交 1ms；附加首次容器点击 24.7ms；全量后代扫描 0 次；
  命中检测 2 次（合并移动 1 次、点击 1 次）。这是本地固定样本，不代表任意网站耗时。
- 透明覆盖层下图片/价格/标题点选、内部字段展开测试通过。
- 1,000 条字段缺失与顺序变化提取测试通过。
- 搜索输入、即时翻页、保存重放和两页 6 条数据采集测试通过。
- 修改文件语法检查通过。

SSL `net_error -100` 表示连接关闭，与上述已复现的网页线程阻塞是不同问题。
没有禁用证书验证，也没有隐藏 Chromium 网络错误。具体站点网络问题仍需网址和复现记录。
