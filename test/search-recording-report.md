# 搜索操作录制回归

2026-09-16，本地 Electron + 本地 HTTP 测试页面。

已实现：
- 打开网址默认启用元素选择，打开网页节点展示步骤名及网址。
- 选中输入框可提取值、配置输入文本；继续点击其他输入框组成组合输入。
- 确认保存元素 CSS 定位及文本为流程节点，并立即执行。
- 输入完成可发送 Chromium 原生 Enter（keydown/char/keyup），支持表单默认提交。
- 搜索导航后保持点选；选择列表数据后可点击下一页并生成循环翻页。
- 原始入口 URL 和搜索输入步骤保留，保存后重放会重新执行搜索。
- 验证码类型配置为图片/滑块/文字，执行时人工处理后继续；支持停止和超时。

通过的验证：
- `test/input-recording.cjs`：组合输入草稿保留，两个字段通过回车表单提交。
- `test/search-workflow.cjs`：真实主窗口 IPC、默认选择、录制输入、搜索跳转、
  列表提取、下一页、规则保存读取、重放两页精确获得 6 条记录。
- `test/captcha-flow.cjs`：未确认不提取，确认后提取，停止时不再提取并移除提示。
- `test/multi-recognition.cjs`：多套识别、切换高亮和预览、生成配置、引导翻页继续正常。
- main、panel、pagecode、input-action、orchestrator 语法检查通过。

限制：未在京东登录态或真实验证码服务上验证；验证码没有自动识别或自动解题。
组合输入为一组固定值，尚未增加截图中的批量文本数据源循环。
页面结构改动可能使保存的选择器失效，会返回执行错误，需要重新点选定位。
